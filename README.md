# Aplicativo de gerenciamento de finanças pessoais - Projeto A3

**UC:** Modelagem de Software

**Professor:** José Padilha
## Descrição

O **aplicativo de gerenciamento de finanças pessoais** é um software desenvolvido para ajudar os usuários a organizar, acompanhar e planejar sua vida financeira de maneira prática e intuitiva.

A aplicação permite que o usuário cadastre suas receitas e despesas, classificando-as em categorias personalizadas (alimentação, transporte e etc..), e, com base nessas informações o sistema gera uma visão detalhada das finanças, mostrando saldo mensal, porcentagem de gastos por categoria e tendências de consumo ao longo do tempo.

O sistema foi projetado com foco em usabilidade e acessibilidade, com uma interface moderna, responsiva e mobile-first, permitindo acesso via smartphone, tablet e computadores. A aplicação também adota uma arquitetura modular, com banco de dados relacional em MySQL, fornecendo integridade e consistência das informações. 

Na parte de apresentação temos um protótipo desenvolvido no Figma, e o sistema foi modelado utilizando diagramas UML.

### Em resumo
O gerenciador de finanças pessoais é um aliado no controle financeiro, auxiliando o usuário a entender seus hábitos de consumo, planejar seus gastos e manter uma estabilidade econômica com organização e clareza.

### Principais funcionalidades
- Cadastro de usuários com autenticação segura
- Registro e edição de receitas e despesas
- Criação de categorias personalizadas
- Definição de metas financeiras mensais
- Geração de relatórios gráficos
- Alertas automáticos sobre gastos excessivos
- Histórico financeiro e exportação de dados
